# openclaw-evergreen-memory

`evergreen-memory.skill` is an OpenClaw skill for file-based memory, session-scoped continuity, lightweight wrap-ups, and continuous self-improvement.

This version is implementation-oriented: when used, it should guide the agent to update the target workspace's relevant `.md` files so the behavior becomes intrinsic rather than remaining a detached policy.

## Contents

- `evergreen-memory.skill` — packaged skill artifact

## Install

Download the `.skill` file and install it into your OpenClaw instance according to your normal skill import flow.

## What it covers

- daily memory files
- session-scoped memory files
- durable long-term memory promotion
- immediate and inactivity-based wrap-ups
- retrospectives and self-improvement
- updating workspace instruction files to embed the behavior
