# openclaw-evergreen-memory

`evergreen-memory.skill` is an OpenClaw skill for file-based memory, session-scoped continuity, lightweight wrap-ups, and continuous self-improvement.

## Contents

- session-scoped memory files
- durable long-term memory promotion
